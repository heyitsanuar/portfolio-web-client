# Skill icon sources

The SVGs in this directory are stored locally and rendered as decorative
companions to visible technology labels.

## Simple Icons

Source: <https://github.com/simple-icons/simple-icons>

License: CC0 1.0 Universal. See `LICENSE-SIMPLE-ICONS.md`.

Files: `javascript.svg`, `typescript.svg`, `react.svg`, `redux.svg`,
`vuedotjs.svg`, `reactivex.svg`, `nodedotjs.svg`, `dotnet.svg`, `jenkins.svg`,
`claude.svg`, `githubcopilot.svg`, `cursor.svg`, `modelcontextprotocol.svg`,
`jest.svg`, `testinglibrary.svg`, `selenium.svg`, and `gradle.svg`.

## Devicon

Source: <https://github.com/devicons/devicon>

License: MIT. See `LICENSE-DEVICON.txt`.

Files: `knockout.svg`, `java.svg`, and `azure.svg`.

## Generic icon

Simple Icons and Devicon did not provide a matching ChatGPT asset when these
icons were added. `SkillIcon.astro` therefore renders an original neutral chat
glyph for ChatGPT. It does not imitate the OpenAI or ChatGPT brand mark.
