## User Story
As a developer, I want a minimal Astro project configured with TypeScript and Tailwind CSS so that the portfolio has a fast and maintainable foundation.

## Acceptance Criteria
- [ ] Astro is configured.
- [ ] TypeScript strict mode is enabled.
- [ ] Tailwind CSS is configured.
- [ ] `npm run dev` works.
- [ ] Production build succeeds.
- [ ] `src/components`, `src/data`, `src/layouts`, `src/pages`, and `src/styles` exist.

## Constraints
- Do not add React unless a component genuinely requires it.
- Avoid unnecessary dependencies.
- Prefer Astro and vanilla TypeScript.

## Agent Notes
Before implementation:
- Read `AGENTS.md`.
- Inspect the existing architecture.
- Propose a plan before making changes.
- Reuse existing components and patterns.
- Do not modify unrelated functionality.

Before completion:
- Review the implementation against this issue.
- Run required quality checks.
- Report changed files.
- Report tests performed.
- Report assumptions or remaining limitations.
