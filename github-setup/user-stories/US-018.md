## User Story
As a visitor using assistive technology or keyboard navigation, I want the portfolio to be accessible.

## Acceptance Criteria
- [ ] Semantic HTML and heading hierarchy are correct.
- [ ] Keyboard navigation and visible focus states work.
- [ ] Color contrast is appropriate.
- [ ] Terminal and carousel have accessible interaction patterns.
- [ ] Icons have appropriate accessible names or are hidden when decorative.
- [ ] Link purpose is clear.
- [ ] Reduced motion is supported.
- [ ] Target Lighthouse Accessibility score is >= 95.
