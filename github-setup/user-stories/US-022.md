## User Story
As the portfolio owner, I want a structured final review so that implementation issues do not reach production.

## Acceptance Criteria
- [ ] Run typecheck, tests, production build, Lighthouse, accessibility review, responsive review, and code review.
- [ ] Manually verify navigation, terminal commands, project/contact links, responsive behavior, hover/focus states, content accuracy, employment dates, technology tags, spelling, console, and 404s.
- [ ] Compare implementation against final desktop/mobile references.
- [ ] No HIGH-severity review findings remain.

## Agent Notes
Before implementation:
- Read `AGENTS.md`.
- Inspect the existing architecture.
- Propose a plan before making changes.
- Reuse existing components and patterns.
- Do not modify unrelated functionality.

Before completion:
- Review the implementation against this issue.
- Run required quality checks.
- Report changed files.
- Report tests performed.
- Report assumptions or remaining limitations.
