## User Story
As a mobile visitor, I want to swipe through projects naturally.

## Acceptance Criteria
- [ ] Mobile supports native swipe and CSS Scroll Snap is preferred.
- [ ] One full project and a small peek of the next project are visible.
- [ ] Previous/next controls are available.
- [ ] A current-project indicator such as `01 / 04` is shown.
- [ ] No heavy carousel dependency is introduced.
- [ ] Desktop remains grid-based.
